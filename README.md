# Code ASCII, Lluvia de Operaciones y Hacker Typer

Tres proyectos independientes, cada uno en su propia carpeta.

| Proyecto | Descripción | Inicio |
| --- | --- | --- |
| [Code ASCII](Code%20ASCII/) | Reproductor de video con efecto ASCII y audio. | Abrir `index.html`. |
| [Lluvia de Operaciones](Lluvia%20de%20Operaciones/) | Juego de cálculo con operaciones que caen y dificultad progresiva. | Instalar dependencias y ejecutar `main.py`. |
| [Hacker Typer](Hacker%20Typer/) | Juego de terminal con misiones, combate y progresión. | Servir la carpeta `public` en un servidor local. |

Cada carpeta contiene instrucciones de ejecución. Los entornos de desarrollo, partidas guardadas y ejecutables de terceros se excluyen del repositorio.
