# Code ASCII

Abre `index.html` en el navegador o ejecuta `Abrir ASCII Cinema.cmd` en Windows.

Selecciona un video y pulsa Reproducir. Incluye pausa, búsqueda, volumen, pantalla completa y alternancia entre ASCII y video original.

Conserva la carpeta `media` junto a `index.html`. Los videos y su audio están incluidos para reproducirse sin conexión.
